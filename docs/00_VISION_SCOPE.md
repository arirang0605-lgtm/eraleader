# 목표·범위·성공 지표

## 최종 목표
한국·미국 주식시장에서 **미래 대장주를 조기에 발견하는 능력**을 갖춘 독립 시스템을 구축한다. 변화의 초기 신호 → 성장 초기 기업 → 잠재 대장주 → 확정 대장주 → 주도력 약화·교체를 실제 운영 시점에 자동 추적한다. 업종별 수요·공급 병목과 기업 성장 가속을 포착하는 것이 주역이다. **과거 데이터·백테스트는 이 기능이 당시 알 수 있었던 정보만으로 작동하는지 검증하는 수단**이며 프로젝트의 최종 목적이 아니다.

## 발굴 원리
1. 구조적 산업 변화: PC/인터넷 → 모바일/클라우드 → AI 인프라 등은 연구용 역사 사례일 뿐, 과거 승자만으로 모델을 만들지 않는다.
2. 가치사슬: 최종 서비스뿐 아니라 반도체/데이터센터/전력/송배전처럼 연쇄적인 수혜와 병목을 평가.
3. 기업: 매출·이익·수주·마진·점유율·현금흐름·전망 수정.
4. 시장: 상대강도, 주봉 추세, 거래대금, 조정 시 방어력.
5. 조기 발굴(민감도)과 허위 후보 감소(정밀도)를 별도의 문제로 측정.

## 대상 범위
- 한국: KOSPI/KOSDAQ (코스피/코스닥 기업, 거래정지·상폐 이력 포함).
- 미국: 미국 주요 상장 거래소 보통주. ADR, ETF, SPAC 등 포함여부는 종목군 메타데이터와 정책으로 관리.
- 기업 성장 초기, 적자 기업, 성숙 기업의 평가방법 구분.
- 분기 실적 공개와 보고기간 경계를 고려한 월/주/일 신호.

## 아웃풋
- 산업 TOP 5, 잠재 대장주 TOP 20, 확정 대장주 TOP 10, 신규 발굴, 강화·약화·교체 후보, 최초 발굴일·시점별 점수·선정 근거·위험요인.
- 한국·미국 별도 시장/날짜/통화/데이터 신선도와 함께 제공.
- 웹, 알림, 일간·주간·월간 보고서, API/JSON/CSV.
- 검증 결과: 리드타임, precision/recall, 초과수익, MDD, 거래비용 후 성과, 시장 국면별 강건성.

## 하지 않을 것(기본 MVP)
- 증권사 계좌 주문·자동매매; EraLeader는 연구·발굴 시스템.
- 근거 없는 미래 가격 예측, 발굴 점수=성공 확률이라는 해석.
- 대규모 LLM 종목별 실시간 호출.
- MarketOS 등 외부 프로젝트에 대한 필수 의존성.

## 개발 완료 판정
실데이터 원본 → PIT 조인 → 점수 → 후보 이벤트 → 저장 → 검증 → 화면 → 알림·보고서의 end-to-end 테스트 결과 확인. 투자 성능은 기능적 완료와 별도로 판단.
