# 대장주 발굴·상태 판정 논리 (초기 실험 규격)

> 아래 수치는 **미검증 가설**이다. 백테스트 후 시장별·업종별로 조정한다. 점수는 성공 확률이 아니다.

## 1. 전체 산업 → 기업 흐름
신기술·정책·자본투자·공급제약의 구조 변화 탐색 → 가치사슬 수혜 산업 정의 → 산업 주도력/성장성 점수 → 기업의 실제 수혜·경쟁력/실적 상승 검증 → 상대강도와 시장 지지 확인 → 후보/확정 상태 판정.

연구 산업 예: AI 반도체, 데이터센터, 전력망, 로봇, 사이버보안, 방산·우주, 정밀의료 등. **이 산업들을 영구 우대하지 않는다**. 관측 데이터로 강도 변화가 검증되어야 한다.

## 2. 초기 점수 100점
| 구성 | 최대점수 | 초기 피처 |
|---|---:|---|
| 산업 성장성 | 20 | 산업 매출·투자·수주 성장, 산업 RS |
| 경쟁력/품질 | 20 | 점유율, 마진, FCF, 자본수익률, 지속성 |
| 실적 모멘텀 | 25 | 매출·영업이익 성장률 가속, EPS 예상 수정 |
| 주가 상대강도·추세 | 25 | 6/12개월 RS, 20주선, 신고가, 조정 방어력 |
| 수급 | 10 | 기관 보유 변화(가용 시), 거래대금·거래량 |
총점 계산: 각 그룹의 업종·시장별 퍼센타일 변환(미래 구간 제외) → 가중 합산. N/A 마스크를 보존하고 과도한 보간을 피함. 원자료·설명 변수 모두 출력.

## 3. 검토할 수치 예시
- 매출 YoY >= 20%, 영업이익 YoY >= 30% (초기 필터, 일률적인 절대 기준 아님)
- 최근 3개월 EPS 추정치 +5~10% 상향(해당 이력 공급자 확보 시)
- 최근 6·12개월 수익률의 시장 상위 15%, 업종 내 상위 3개
- 20주 이동평균 위, 10주·20주 기울기 상승, 거래량 증가, RS 상승
- 장기 월봉 5/10/20개월선 방향은 연구용 상위 Gate; 일봉은 보조 경고·진입 분석. 주봉 신호는 금요일 주간 마감 이후, 월봉은 월말 이후 확정.
- 주가 20주선 이탈이나 펀더멘털 악화 **하나만으로** 자동 매도 단정 금지.

## 4. 연구용 후보 분류
- WATCH: 분석대상/관찰.
- POTENTIAL: 잠재 대장주. 초기 가설 점수 65~79 또는 성장 가속 신호; 검증 전에는 낮은 확신 표시.
- CONFIRMED: 확정 대장주 후보. 점수 80 이상 + 실적/추세/RS 복수 확인 조건 (80만으로 확정 금지).
- WEAKENING: 이전 CONFIRMED가 실적·RS·추세 복수 조건 악화.
- REPLACEMENT_CANDIDATE: 동종 산업 내 경쟁 후보가 기존 주도주보다 실적·RS 우위 지속.
- PAUSED: 데이터 부족·거래정지·진단 불가.
임계값 경계 왕복 방지를 위한 연속 판정 횟수/점수 히스테리시스 설계. 각 이벤트에 직전 상태, 평가시각, 피처, 근거 기록.

## 5. '대장주'의 두 정의 분리
(A) **실시간 모델상 주도주**: 당시에 알려진 데이터로 산업·기업의 실적 및 시장 주도력이 강한 종목. 운영 UI에 표시.
(B) **미래 성과로 정의된 성공 라벨**: 예) 특정 3년 구간 업종대비 누적 초과수익 +100%p, 충분한 유동성과 최대손실 제약 등 사전 정의. A의 평가에만 사용. B는 미래 정보이므로 모델 입력 금지.

## 6. 모델 설명 및 반증
후보별 이름/시장/산업/점수 분해/신규 발견일/상태 변경일/선정 근거 TOP3/반증 조건/데이터 신선도/정보 부족 항목/중요 재무 발표 후 재평가를 기록한다. 성공뿐 아니라 탈락·실패 이력을 보존한다.
