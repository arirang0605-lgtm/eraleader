# 백테스트·검증 실험 계획

## 프로젝트 목표와 백테스트의 역할

**최종 목표는 미래 대장주 조기 발견 시스템 운영**이다. 이 문서는 과거 데이터로 **그 구현 능력을 반증/검증**하는 방법을 정한다. 과거 성과를 극대화하도록 사후 최적화하면 오히려 미래 발굴 신뢰성이 훼손된다. 운영 개시 후 생성된 모든 후보 스냅샷은 최초 발행 시각과 근거를 고정하여 별도 전향적(prospective) 성과 추적을 수행한다. 백테스트 성적이 좋더라도 실제 미래 발견 성능을 보장하지 않으며, 발견 리드타임·오탐률은 CAGR과 별도로 우선 평가한다.

## 개발 순서
데이터/PIT 기준 확보 → 범용 엔진/어댑터 인터페이스 수립 → 산업 신호 개별 검증 → 기업 신호 검증 → 잠재/확정 상태 판정 검증 → 교체 전략 검증 → 통합 포트폴리오 시뮬레이션 → 워크포워드 → 봉인된 최종 평가.

## 핵심 목표: 선정 능력과 투자 성과 분리
**발굴 성능**: 미래 성공 라벨에 대한 precision@K, recall@K, false-discovery rate, 최초 발굴에서 급등까지의 median lead time, 후보 유지기간, 업종 집중도, 이후 6/12/36/60개월 초과성과 분포.
**투자 성능(별도)**: 벤치마크 대비 연율 수익률/CAGR, 변동성, Sharpe(가정 명시), MDD, 회전율, 거래비용·슬리피지·유동성 반영 후 수익, 시장 국면별 성과. EraLeader 기본 출력이 곧 자동매매 신호라는 가정 금지.

## 타당한 과거 재현
- 한국·미국 각각 충분한 검증기간(목표 10~15년 이상, 데이터 품질에 따라 축소 표기).
- 모든 평가 시점의 실제 상장 종목·상폐 종목 포함.
- 공시·추정치의 첫 이용가능 시점, 수정 버전, 재편·산업분류, 편향 없는 가격.
- 일/주/월 고정 스냅샷을 생성하고 미래 누수 자동 테스트.
- 후보 선정 후 다음 거래가능 시점만 평가용 체결 시뮬레이션에 사용.
- 분할/배당/스핀오프 처리, 매매 제한, 거래 정지 및 거래비용.
- 각 평가 기간의 미래 라벨은 피처 집합에 절대 포함하지 않는다.

## 비교 기준
KR: KOSPI, KOSDAQ, 관련 업종지수, 단순 6-12개월 모멘텀 TOP K.
US: S&P 500, NASDAQ-100(적합한 범위), 업종지수, 동일 종목군 단순 모멘텀 TOP K.
전망치 없는 데이터 대안과 컨센서스 포함 실험을 **별도로 표시**한다.

## 실험 구조
1. 단순 baseline(동일가중·모멘텀) 등록.
2. 산업 단독, 기업 단독, RS 단독, 결합 모델을 각각 동일 종목군/기간에서 비교.
3. 개발 구간에서 점수 임계치 선택. 분기/연 단위 walk-forward에서 과거에만 학습/보정.
4. 마지막 구간은 결과 평가 전까지 미사용(Holdout). 실패했다고 재학습에 사용하면 새 독립 검증 기간 필요.
5. 실패한 실험도 결과/설정/코드 버전을 기록하여 선택편향 방지.
6. 성공 지표 외 오류율, 데이터 커버리지, 불확실성(부트스트랩/구간)까지 보고.

## 테스트 계층
- 스모크: toy dataset, 수초 단위, 매 변경.
- 모듈: 해당 신호 전략, 소규모 실데이터, 수정 시.
- 통합: 월간·릴리스, 비용과 end-to-end 확인.
- 장기 PIT 백테스트: 주요 릴리스/전략 변경 시.
- 봉인된 최종 평가: 정책을 고정한 뒤 1회성 연구 통제.

## 핵심 함정
서바이버십 편향, 룩어헤드, 데이터 스누핑, 최적화/매개변수 과적합, 사후 산업 선택, 회사 주가 분할 보정 오류, 거래불가, 저유동성, 생존자 사례만 분석하는 편향. 모두 테스트 및 리포트에서 표시.

## 완료 판정
명령어 재현 가능, 데이터 커버리지/기간/종목수 명시, PIT 실패 0, 벤치마크 및 비용 후 결과 존재, 설정 해시·실험 ID가 있는 산출물 생성. 수익이 좋다는 이유만으로 구현 완료 판정하지 않는다.
