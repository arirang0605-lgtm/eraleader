# 최종 사용자 결과·알림·보고 요구사항

## ① 웹 대시보드(PC·휴대폰 반응형)
- 한국/미국 시장 전환; 산업 TOP 5; 확정 대장주 TOP 10; 잠재 후보 TOP 20.
- 신규 발견/확정 승격/주도력 약화/교체 후보/성장 가속 이벤트.
- 종목 상세: 점수 5개 구성, 실적·RS/월·주·일 추세, 최초 선정일, 누적성과, 선정 이유·반증 조건, 데이터 누락/갱신시간.
- 과거 시점으로 되돌려 당시 랭킹 확인, 당시 가용 정보만 보여주기.
- 선정 이후 성과와 벤치마크 차트, 백테스트 버전 및 가정 표시.
- 데이터 갱신 지연·오류 시 경고; 예시/가상 데이터 표시 필수.

## ② 자동 알림
이벤트 타입: NEW_POTENTIAL, PROMOTED_CONFIRMED, REPLACEMENT_SIGNAL, WEAKENING, ACCELERATION.
- 상태 이벤트가 새로 발생할 때만 발송; 중복전송 방지 키 = (security_id, event_type, as_of, model_version).
- 거래소 휴장/재시도·다중 사건 병합 정책.
- 알림에는 시장/종목/선정 사유/기준시각/이벤트 연결 링크 포함.
- 전송 채널(텔레그램·이메일·푸시)은 설정형. 구체 채널은 추후 결정.
- 자동 주문은 수행하지 않음.

## ③ 정기 보고
- 매일: 한국·미국 순위 변동, 새 후보, 주도 산업, 데이터 기준 시각.
- 매주: 산업별 리더십 변화, 확정 TOP10/잠재 TOP20, 주간 상태 전이.
- 매월: 최초 발굴 이후 1/3/6/12개월 실현 관찰성과(표본 충분 시), 성공/실패 사례, 선정 오류와 백테스트 성능·기준 변경.
- 출력: 웹 페이지 + 다운로드 PDF + 이메일 발송 옵션. 발행 시각은 결정 전.
- 보고의 모든 표/문장은 공통 저장된 분석 결과를 사용. LLM 해설은 선택적, 별도 비용 기록.

## 초기 개발 순서
1. 로컬 브라우저에서 읽는 정적/간이 대시보드
2. 이벤트 원장(event ledger) 생성 및 중복 검증
3. 단일 채널 테스트 알림
4. 일간 템플릿→주간→월간→PDF
5. HTTPS 로그인·클라우드 배포·장애 감시

## 보안
웹 인증·접근권한, 토큰과 API 키 비노출, 알림에 개인 API 키 미포함, 데이터 공급자의 재배포 약관 준수.
