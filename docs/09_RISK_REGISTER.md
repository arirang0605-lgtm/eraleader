## 우선순위
R1/R2/R4/R5 최우선. 서비스 완성도와 실제 투자 유효성은 별도 품질 게이트에서 판정한다.

## 사고 대응
증상 확인 → 재현 → 오류 유형 분류(데이터/로직/운영) → 영향기간과 과거 결과 무효화 범위 명시 → 수정 → 회귀/백테스트 재실행 → 재발 방지 테스트와 기록.
