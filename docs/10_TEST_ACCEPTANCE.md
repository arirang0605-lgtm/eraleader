# 테스트 계획 및 완료 판정

## 자동 테스트 유형
- 구조: 패키지 설치/CLI 실행/JSON 계약/결과 직렬화.
- 데이터: 중복·누락·시간대·상장/상폐·분할/배당·정정공시·오염된 공급자 응답.
- PIT: 결정시각 이후 데이터 삽입해도 이전 후보 랭킹 **불변**.
- 점수: 누락 데이터, 적자전환, 분모 0, 극단값, 업종 내 정규화, 순위 동률.
- 상태: 최초 후보/확정/약화/교체 이벤트, 재실행 중복방지, 주봉/월봉 확정시각.
- 백테스트: 매수 체결시차, 수수료·슬리피지, 지수 비교, 상폐손실, 재현성.
- 출력: 한국·미국 화면 동일 스키마, 최신 갱신시각, 다운스트림 경고 전달.
- 알림·보고: 이벤트 1회만 전송, 휴장일 동작, 오류 재시도·발송 실패 기록.
- 배포: 인증/비밀 관리, 재시작 복구, 백업 복원.

## 품질 게이트
- G0: 외부 자료 없이 toy test 통과; 실제 투자 성과 주장 불가.
- G1: 실제 시장 데이터 1개 소스 + 오류 처리 증명.
- G2: 다년 PIT 데이터 + 과거 시점 검증 + 편향 통제.
- G3: 산업/기업/후보 알고리즘 baseline 초과 여부와 불확실성 기록.
- G4: 이력·화면·알림·보고 end-to-end 재현.
- G5: 배포 보안·운영 모니터링·자동 복구.

## 제출 증거
실행 명령, 테스트 개수·성공/실패·시간, 데이터 기간·시장·종목 수, 평균 누락 비율, 소스/파라미터 버전, 산출물 경로, 중단 원인, 결과 해시/CI 링크. 사용자 보고는 핵심만.

## 금지 표현
가상 데이터 테스트만으로 '대장주 발굴 성능 검증 완료' 금지. 코드가 있다는 이유로 '기능 완료' 금지. 과거 승자 몇 개를 맞췄다고 미래 수익을 약속하지 않는다.
