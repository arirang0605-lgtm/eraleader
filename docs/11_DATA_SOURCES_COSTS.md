# 데이터 공급자·준비물·비용 판단

## 사용자 준비 우선순위
1. 별도 GitHub Private 저장소: eraleader. 원본 코드를 확인하고 기존 프로젝트와 충돌 없이 연결.
2. 한국 KRX OPEN API 이용신청/인증키·세부 제공항목 확인.
3. OpenDART 인증키 신청.
4. 미국 SEC EDGAR 재무공시는 공개 접근이 가능하지만 요청 식별·제한 준수.
5. 미국 일별 주가/상장폐지 및 기업행동 데이터: 품질·장기 보장 범위를 비교 후 공급자 선택.
6. 컨센서스 과거 스냅샷: 무료 데이터로 불충분하면 가격/라이선스 검토.
7. 알림 채널·웹 공개 범위·클라우드 예산은 MVP 이후 결정.

## 비용 원칙
- 가격·쿼터·서비스 제공 현황은 수시로 바뀌므로 사용 직전 공식 안내로 재확인.
- 실전 데이터 핵심 품질에 직접 필요한 부분에 먼저 예산 투입.
- 클라우드는 초기에 구매하지 않고 로컬에서 검증.
- 외부 API 키는 .env/비밀관리, Git 추적 금지.
- 약관상 재배포할 수 없는 원데이터는 외부 공개 API에서 제공하지 않음.

## 데이터 확보 순서
공급자 계약/승인 → 샘플 호출 → 심볼·시점·단위 매핑 → 원본 캐시 → 증분 수집 → 과거 범위 보강 → 품질 게이트 → PIT 재현. 허가 전에는 공식 샘플/공개 자료로 테스트 가능 범위를 명확히 표시.

## 사전 검증 질문
가격에 상장폐지 종목이 포함되는가? 거래소별 종목 이력을 얻을 수 있는가? 발표시각과 기업행동이 있는가? 변동 데이터 수정 이력이 남는가? 업데이트 지연/쿼터/리포트 재배포 제약은? 과거 10~15년 기간이 실제 가능한가?

## 상세 구현 문서
데이터 유형별 API 접근, 과거 시점 자료, 원본 저장, 수집 스케줄 및 데이터별 테스트는 [13_DATA_COLLECTION_IMPLEMENTATION.md](13_DATA_COLLECTION_IMPLEMENTATION.md)를 기준으로 한다.
