# EraLeader 설계도·투자 발굴 지도 보완 필요 항목

> 2026-10-10 검토. 현재 1~6단계 전체 그림과 세부 PNG/SVG는 **개발 방향을 공유하기에 충분**하다. 새 장식용 그림을 늘리는 것보다 아래 **검증에 필요한 결정·데이터·코드**를 보완하는 편이 우선.

## 1. 이미 준비된 것

- 전체 설계도 1장: `EraLeader_전체설계도_1-6단계_세부번호.png` (1_1~6_5 총 30개 고유 작업).
- 1단계 데이터 수집 그림 1장, 2~6단계별 상세 그림 5장(총 7장; 각각 PNG·SVG).
- 데이터별 수집 명세 `docs/13_...`, 2~6 단계별 구현 명세 `docs/14_...`~`docs/18_...`, 30개 번호표 `docs/21_...`.
- 백테스트엔진 로컬 데이터 재활용 점검·코드 스모크 증거 `docs/23_...`.
- **아직 없는 것:** 실제 주도주 분석 코어, PIT 데이터 엔진, 검증된 투자성과, 정상 작동하는 화면/알림/보고.

## 2. 추가로 확정해야 하는 중요한 연구 규칙

| 우선 | 항목 | 왜 필요한가 | 현재 단계 |
|---|---|---|---|
| P0 | **'미래 대장주' 평가 라벨** (기간, 시장/업종 초과수익 기준, 유동성) | '조기에 발견'의 정답이 있어야 성능 비교 가능 | 문서에 후보 정의만 있음, **미확정** |
| P0 | **과거 당시의 종목군**과 상폐/합병, 가격 기업행동 계약 | 생존편향/보정 오류로 과장된 수익 차단 | 로컬 가격 자료 있음, **검증 미완료** |
| P0 | **공시 이용가능 시각** (정정·지연 포함) | 재무·컨센서스 미래정보 누출 방지 | PIT 설계는 있음, **실제 데이터·코드 없음** |

| P2 | **웹 화면 UX 및 알림 채널** | 최종 사용자 사용성 | 구조도 있음, 채널·로그인·배포 미정 |
| P2 | **백업/복구·비용 상한·API 라이선스** | 장기 운영 안정성 | 정책 필요 |

## 3. 그림 자료가 더 필요하다면 3개만 권장

**지금 당장 추가 제작보다 실코드 검증이 먼저.** 다음은 실제 구현 단계에 맞춰 만들면 가치가 큰 작업용 그림이다.

1. **PIT/데이터 계보·오류 흐름도** — 가격/공시 원본과 `available_at`, 정정·상폐·분할 경로, 품질 FAIL시 차단 단계 표시. (2_1~2_5 코딩 전/중)
2. **후보 상태 머신 상세 전이도** — WATCH→POTENTIAL→CONFIRMED→WEAKENING/REPLACEMENT, 히스테리시스·PAUSED·해제 조건. (4_1~4_5 개발 시)
3. **백테스트 평가/사용자 화면 실제 예시** — 당시 후보 스냅샷→리드타임/precision/업종 초과수익→대시보드/알림/보고서까지, 검증된 결과와 가상 UI 분리. (5~6단계 코딩 시)

추가 그림은 한 장당 분명한 용도/검증 항목이 있을 때만 제작. 현재 전체도와 중복되는 이미지는 만들지 않음.

## 4. '투자 지도'에서 개발 지도로 구분해야 하는 내용

```text
시대 산업 변화(가설)
    ↓ 공시/산업 데이터와 시장 가격의 동시 검증
산업 평가 → 기업 실적/경쟁력 → 주가·RS
    ↓
잠재 대장주 [조기 발견/거짓 후보 검증]
    ↓ 다중 신호 확인
확정 주도주 [실적·추세 지속성]
    ↓
약화·교체 [상태 이력/반증]
    ↓
PIT 백테스트 [정밀도·리드타임·시장 초과성과·MDD]
    ↓
웹·알림·정기보고 [현황·근거·실패사례까지 보존]
```

- **EraLeader는 후보 발굴 엔진**이고, 포트폴리오 비중/실거래 자동집행/리밸런싱은 별도 프로젝트·검증 후 연결. 기본 설계도가 투자 수익을 보장하는 지도가 되는 것은 아니다.
- 모델 선택 GPT-6 Medium(기초 코딩), High(발굴 로직·PIT 오류), Extra High(난이도 높은 시계열 검증, 선택 가능 시)를 **필요할 때만 안내**. 모델 변경 자체로 잔여 에이전트 한도가 회복되는 것은 아니다.
