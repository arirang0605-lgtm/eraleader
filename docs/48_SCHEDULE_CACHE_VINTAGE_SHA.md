# 2026-10-10 — 6_5 캐시 실제 바이트 버전 감사 및 스케줄러 재검증

## 발생 가능했던 운영 결함

기존 `run_scheduled` 체크포인트는 마지막 KR·US 관측일만 비교했다. 공급자가 과거 특정 일봉 종가·기업행동을 수정해도 가장 최근 날짜가 변하지 않는다면, 과거 자료가 바뀐 사실을 알지 못한 채 `SKIPPED_UNCHANGED_CACHE`로 넘어갈 수 있다. 이는 미래 후보 발굴 프로그램에서 데이터 수정 빈티지와 보고서의 재현성을 해치는 결함이다.

## 기존 정상 코드 보존, 좁은 범위의 보강

- `src/eraleader/local_schedule.py`에 `latest_cache_fingerprints`·`active_cache_files` 추가. `read_market_bars`가 실제 사용하는 **한국 직전 550일 범위의 모든 연도별 Parquet**와 미국 주봉 파일을 스트리밍 SHA256 한다. 예컨대 2026-10-02 분석에는 KR-2025, KR-2026 및 US 자료가 해당된다. 최신 연도 2026 파일만 검사해서 2025의 정정 버전을 놓치지 않는다.
- 원천 SHA256 해시가 이전 정상 배치 체크포인트와 **모두 동일**하고 기존 ZIP 백업도 SHA 검증을 통과해야 `SKIPPED_UNCHANGED_CACHE`로 처리한다. 이전 날짜만 있는 과거 체크포인트에는 원천 해시가 없으므로 신규 정상 버전으로 재처리한다.
- 배치 실행 전·배치 완료 후·ZIP 완료 직후에 최신 일자 및 모든 관련 파일 SHA를 다시 대조한다. **분석 중** 또는 **백업 중** 원천 캐시가 바뀌거나 필수 이전 연도 파일이 사라지면 정상 체크포인트 갱신을 **중단**하고 다음 배치의 재시도를 허용한다.
- 파일 해시가 동일하면 기존 결과/백업을 재사용한다. 파일이 같은 크기·같은 최종 관측일이라도 바이트가 바뀌면 재실행한다. 심볼릭 링크·누락·0바이트 원본도 차단한다.
- 신선도 게이트가 먼저 수행되므로 **오래된 미국 캐시를 시간당 전체 해시 분석하거나 그 날짜로 실시간 후보/알림을 생성하지 않는다**. `--allow-stale-research`를 명시했을 때만 연구용 실행 가능. 누출된 키 또는 원시가격은 SHA 보고서/깃에 포함하지 않는다.
- 기존 macOS `launchd` 설정, 오프라인 배치, PIT 원장, 기업행동 엔진, `CycleOS-Lab_BacktestEngine` 원본 **수정 없음**.

## 실제 검증

```bash
cd /Volumes/T5DATA/eraleader
PYTHONPATH=src python3 -m pytest tests/test_schedule_cache_vintage.py tests/test_local_schedule.py -q
PYTHONPATH=src python3 -m pytest tests -q
python3 scripts/check_handoff.py
```

- **추가 테스트 10건** (`tests/test_schedule_cache_vintage.py`): 모든 과거 참조연도 포함, 과거 KR 정정/US 정정에 따른 날짜 동일 재실행, 분석/백업 중 수정시 미완료, 필수 연도 누락·symlink 차단, 구형 날짜만 있는 체크포인트 재처리, 오래된 캐시 해시 계산 생략. 기존 로컬 스케줄러 회귀 통과. 기본 360개 → **370 pytest PASS/0 FAIL**.
- 읽기 전용 실제 T5DATA 데이터를 열어 **세 원본 SHA256 스트리밍 검사 실행**: 한국 2025년 파일(`KR-2025`), 2026년(`KR-2026`), 미국 주봉(`US`). 마지막 관측일 KR `2026-10-02` / US `2026-02-26`. 실제 로컬 기준 2026-10-10, 관측 자료 나이 KR **8일**, US **226일**로 `SKIPPED_STALE_CACHE` 정확히 반환; 실전 자동 메시지 **0건**.
- 해시 검사는 입력 바이트에 대한 **일관성**을 확인할 뿐 공식 거래소 원천·업데이트 승인 이력·독립 `retrieved_at` 공증 또는 법적 PIT 적격성을 증명하지 않는다. 합성 가격 정정 테스트가 실제 미래 대장주를 발굴한 증거는 아니다.
