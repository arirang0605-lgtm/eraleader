# 2_3 / 2_5 — Declared exchange session-close as-of gate

The opt-in `audit-total-return --session-clock <local-json>` checks raw-price AND reference total-return-index `available_at` against a separate exchange-session closing-time assertion. Legacy CLI input stays compatible if this option is absent; the legacy path **does not** prove a pre-close timestamp is safe.

Clock JSON schema: `eraleader.session_close_manifest.v1`, `market` KR or US, distinct `source_id`, `publisher_id_claimed`, timezone-aware `published_at` and `retrieved_at`, and a `sessions` list of `{session,close_at}` with full exact matching coverage. A timestamp is converted to the exchange zone (`Asia/Seoul` or `America/New_York`) before verifying its session date, including daylight-saving transitions. The asserted clock must have been retrieved by the original decision cutoff, and published by its claimed retrieval time. Both price and index must be published at or after the claimed session close and no later than the evaluation cutoff enforced by the existing total-return calculation.

If any required source, session, timestamp or pre-close record fails, the CLI refuses the audit **before publishing the output JSON**. Valid input emits `declared_session_close_audit` with a canonical manifest SHA256, source claim and checked session count; `independent_exchange_clock_verified=false` and `historic_pit_certified=false` always. This is a self-declared clock, not official exchange-session attestation or independent PIT/source certification. An intentionally dishonest same-day close time in the self-declared manifest is not detectable without an authoritative third-party calendar.

Reproduction (offline, no API): `PYTHONPATH=src python3 -m pytest tests/test_session_close_gate.py tests/test_adjusted_crosscheck.py tests/test_market_local_return_pit.py tests/test_corporate_returns.py -q`; full: `PYTHONPATH=src python3 -m pytest tests -q`. Synthetic CLI success and injected pre-close rejection are exercised by `test_cli_clock_option_fails_before_publishing_results`. No raw market data or secrets leave T5DATA.
